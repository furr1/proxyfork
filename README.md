# ProxyFork 🛡️

**ProxyFork** — минималистичный и надежный клиент системного проксирования для Windows (L3 / TUN-режим) на базе **CustomTkinter** и ядра **sing-box + Wintun**.

В отличие от стандартного системного прокси Windows (WinINet), который затрагивает только браузеры, ProxyFork перехватывает трафик **всей операционной системы на уровне сетевых пакетов**:
* Все браузеры (Chrome, Firefox, Edge, Brave, Яндекс)
* Все десктопные приложения (Telegram, Discord с голосовыми вызовами, Steam)
* Игры и сетевые службы
* Консольные утилиты (`curl`, `git`, `docker`, `powershell`, `cmd`)

---

## ✨ Основные возможности

* **Полный L3 TUN перехват**: весь TCP и UDP трафик системы направляется в SOCKS5-прокси.
* **Поддержка UDP**: голосовые звонки в мессенджерах, онлайн-игры и DNS работают стабильно.
* **Защита от DNS-leak**: встроенный DNS-перехватчик резолвит запросы через прокси, исключая утечки провайдеру.
* **Список исключений (Bypass)**: возможность указать процессы (`telegram.exe`, `discord.exe` и др.) или выбрать `.exe` файл через проводник, трафик которых пойдет напрямую в интернет в обход прокси.
* **Изолированное хранение настроек**: настройки хранятся в защищенном системном каталоге `C:\Program Files\ProxyFork\settings.json`, не засоряя рабочие папки.
* **Работа в системном трее**: возможность сворачивать окно в трей рядом с часами.
* **Авто-запрос UAC**: автоматическое повышение прав администратора для работы с виртуальной сетевой картой Wintun.

## 🚀 Быстрый старт (для пользователей)

1. Скачайте последний релиз **`ProxyFork.exe`** из раздела [Releases](https://github.com/).
2. Запустите `ProxyFork.exe` (подтвердите запрос прав администратора UAC).
3. Введите данные вашего SOCKS5-прокси (Хост, Порт, Логин, Пароль).
4. *(Опционально)* На вкладке «Исключения» добавьте программы, которые должны работать напрямую.
5. Нажмите кнопку **«ПОДКЛЮЧИТЬ»**.

## 🛠 Запуск из исходного кода (для разработчиков)

### Требования
* Windows 10 / 11 (x64)
* Python 3.10+

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/proxyfork.git
   cd proxyfork
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Скачайте сетевые бинарники (`sing-box.exe` и `wintun.dll`):
   ```bash
   python download_core.py
   ```

4. Запустите приложение:
   ```bash
   python main.py
   ```

### Сборка в один автономный `.exe`:
```bash
build.bat
```
Файл будет скомпилирован в папку `dist/ProxyFork.exe`.
