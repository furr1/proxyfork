# ProxyFork 🛡️

**ProxyFork** — быстрый, надежный и минималистичный клиент системного L3 TUN-проксирования для Windows на базе **CustomTkinter** и сетевого ядра **sing-box + Wintun**.

В отличие от стандартного системного прокси Windows (WinINet), который затрагивает только браузеры, ProxyFork перехватывает и туннелирует трафик **всей операционной системы на уровне сетевых пакетов**:
* **Все браузеры**: Chrome, Opera GX, Firefox, Edge, Brave, Яндекс.Браузер
* **Любые десктопные клиенты**: Telegram, Discord (включая голосовые каналы), Steam, Battle.net
* **Игры и онлайн-сервисы** с полной поддержкой UDP
* **Консольные утилиты**: `curl`, `git`, `docker`, `powershell`, `cmd`, `ssh`

---

## ✨ Основные возможности

* **Полный L3 TUN перехват**: весь TCP и UDP трафик операционной системы прозрачно направляется в SOCKS5-прокси через виртуальный сетевой адаптер Wintun.
* **Сетевой стек Mixed (gVisor + System)**: высокопроизводительная гибридная обработка пакетов (пользовательский стек для соединений L4 + нативный Windows для скорости), исключающая зависания сетевого стека Windows.
* **🇷🇺 Раздельное туннелирование сайтов РФ (Split Tunneling)**:
  * Встроенный переключатель в интерфейсе: `🇷🇺 Сайты РФ (.ru, Яндекс, банки) напрямую`.
  * Российские домены (`.ru`, `.рф` / `xn--p1ai`, `.su`), Яндекс, ВК, Госуслуги, банки и локальные сервисы идут **напрямую на полной скорости провайдера** без капч и лишней нагрузки на прокси.
  * Прямой DNS-резолвинг для российских доменов (CDN отдает ближайшие быстрые IP).
  * Горячее применение на лету без необходимости ручного переподключения.
* **Глубокий анализ протоколов (Action Sniffing)**: автоматическое распознавание TLS SNI и HTTP Host в потоке данных для точного разделения трафика по доменам даже при прямом обращении по IP.
* **Мгновенное подключение и мягкая остановка (Graceful Shutdown)**:
  * Чистая остановка sing-box через сигналы `CTRL_BREAK_EVENT` — Wintun выгружается за **0.02 секунды** без оставления мусорных виртуальных адаптеров в реестре Windows.
  * Перехватчик системного выключения ПК (`SetConsoleCtrlHandler` на события Logoff/Shutdown) предотвращает «зависание» адаптера при перезагрузке.
  * Умная синхронизация готовности интерфейса без слепых задержек.
  * Автоматический повтор (Auto-retry) при задержке освобождения адаптера операционной системой.
* **Мониторинг скорости в реальном времени**: живой счетчик отдачи и скачивания (`↓ Скачивание / ↑ Отдача`) на панели сетевой информации и в подсказке трея.
* **Сверхбыстрый DNS (TCP DNS + Persistent Cache)**: надежные DNS-запросы через туннель с сохранением в локальную базу SQLite (`cache.db`) для ответов за 0–1 мс, встроенная защита от утечек IPv6 (`ipv4_only`).
* **Оптимизация потокового видео (QUIC Reject)**: автоматическое переключение видеосервисов (YouTube, Twitch) с UDP 443 на стабильный TCP для максимальной скорости без буферизации.
* **Продвинутый список исключений (Bypass)**:
  * Добавление процессов по имени или выбор файла `.exe` через проводник.
  * Полная нечувствительность к регистру символов и фильтрация по регулярным выражениям путей (`process_path_regex`).
  * Кнопка **«🔄 Применить сейчас»** для мгновенного обновления правил без ручного перезапуска.
* **Журнал работы с копированием в один клик**: встроенная кнопка **«📋 Скопировать лог»** с мгновенным подтверждением копирования для быстрой диагностики.
* **Таймер активной сессии**: динамический счетчик времени подключения (`⏱️ ЧЧ:ММ:СС`) в строке состояния и в подсказке иконки в трее.
* **Сторож соединения (Watchdog)**: автоматический фоновый контроль состояния сетевого адаптера и ядра `sing-box`.
* **Безопасное хранение настроек**: конфигурация хранится в изолированном системном каталоге `C:\Program Files\ProxyFork\settings.json`.
* **Работа в системном трее**: сворачивание в область уведомлений при закрытии окна.
* **Вшитый манифест UAC**: автоматический запрос прав администратора при запуске файла без лишних диалогов.

## 🚀 Быстрый старт (для пользователей)

1. Скачайте последний релиз **`ProxyFork.exe`** из раздела **[Releases](https://github.com/furr1/proxyfork/releases)**.
2. Запустите `ProxyFork.exe` (подтвердите запрос прав администратора UAC).
3. Введите данные вашего SOCKS5-прокси (Хост, Порт, Логин, Пароль).
4. *(Опционально)* На вкладке **«Исключения (Bypass)»** укажите программы, которые должны идти в интернет напрямую мимо прокси.
5. Нажмите кнопку **«ПОДКЛЮЧИТЬ»**.

## 🛠 Запуск из исходного кода (для разработчиков)

### Требования
* Windows 10 / 11 (x64)
* Python 3.10+

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/furr1/proxyfork.git
   cd proxyfork
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Скачайте сетевые бинарники (`sing-box.exe` и `wintun.dll`):
   ```bash
   python download_core.py
   ```

4. Запустите приложение:
   ```bash
   python main.py
   ```

### Сборка в один автономный `.exe`:
```bash
build.bat
```
Скрипт использует `ProxyFork.spec` и компилирует готовый исполняемый файл в папку `dist/ProxyFork.exe` с вшитыми библиотеками, иконками и манифестом администратора.

## 📁 Структура проекта

```
proxyfork/
├── bin/                    # Сетевое ядро (sing-box.exe, wintun.dll)
├── core.py                 # Логика TUN, конфиг sing-box, DoH, Wintun, UAC
├── gui.py                  # Графический интерфейс на CustomTkinter + Pystray + Watchdog
├── main.py                 # Точка входа приложения
├── download_core.py        # Скрипт автоматической загрузки sing-box и Wintun

├── build.bat               # Скрипт компиляции в единый EXE
├── start.bat               # Быстрый запуск pythonw main.py
├── requirements.txt        # Зависимости Python
├── icon.ico / icon.png     # Иконки приложения
└── README.md
```
